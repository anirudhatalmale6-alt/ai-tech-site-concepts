04 — Build notes

How I'd build it

  • Gutenberg blocks on a lightweight block theme — no Elementor. Fewer scripts, faster pages, and editing looks like the live site. Happy to switch to Elementor if your team already knows it; just say so.
  • Every section on this page is an editable block. Headings, body copy, service cards, logos and images all change from the WordPress editor — no code, no developer.
  • Responsive from the start. The concepts above already adapt down to phone width; try them on your mobile.
  • SEO-ready — clean heading order, meta titles/descriptions per page, XML sitemap, schema for the organisation, and fast Core Web Vitals from the low script count.
  • Contact form with spam protection, an autoresponder, and every submission stored in the dashboard as well as emailed.
  • Documentation at handover: theme and plugin list, how to edit each page type, how to add a service, and how to change the navigation.
